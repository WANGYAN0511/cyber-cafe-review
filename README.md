# 🎮 极致电竞 · 好评生成器

扫码写好评，一键复制粘贴！

## 使用方式

1. 打开 → [好评生成器](https://wangyan0511.github.io/cyber-cafe-review/review-generator.html)
2. 选择风格（丰富版 / 随意版 / 简短版）
3. 点击「刷新评价」生成新文案
4. 点击「一键复制」→ 去大众点评/美团粘贴

## 文件说明

- index.html — 扫码入口页（带自动生成二维码）
- eview-generator.html — 好评生成器主页面
